# Adresses des maisons — sécurité

> Déplacé tel quel depuis `CLAUDE.md` (§1 « Fact block canonique ») le 24/11/2026, pour alléger le fichier chargé à chaque session. Ces règles restent en vigueur ; `CLAUDE.md` n'en garde qu'un résumé (§1 « Règles d'or ») et renvoie ici.

- **Adresses des maisons (12/10/2026, cambriolage, décision Jérôme ; lot « sécurité des adresses » du 13/11/2026)** : le site publie la zone (`houseZone`) et un point public à ≈ 500 m (`publicGeo`), jamais la rue ni les coordonnées exactes, ni dans le texte ni dans le JSON-LD. **Aucune rue de maison ne s'écrit dans le dépôt** : ni dans `src/`, `scripts/`, `tools/`, `content/`, `public/`, ni dans un commentaire, un test, un SQL ou une sauvegarde. `HOUSES` n'a plus de champ `streetAddress` ; `PROPERTY_ADDRESSES` et `houseAddressLine()` n'existent plus ; `LAVILLA_NAP` ne porte plus d'adresse. Un écran qui a besoin d'une adresse (bail, quittance, état des charges, courrier de révision du loyer) la lit **en base à l'exécution** (`properties.address`, session connectée, RLS ; mise en forme `src/lib/propertyAddress.ts`), sans valeur par défaut dans le code ; **jamais de variable d'environnement de build** pour ces valeurs (Vite les recopierait dans le JavaScript servi). Dans `src/` et `scripts/`, une adresse d'exemple (commentaire, page de démonstration) s'écrit « N rue des Exemples » ou « N rue du Faux-Exemple », seules formes en liste blanche ; dans les tests de `tools/`, toute adresse est inventée, avec un nom de voie qui n'existe pas dans l'agglomération (« impasse des Tests », « avenue Érable-Fictif »). Seule exception : le siège social de la société éditrice, publié par obligation sur les pages légales (`LEGAL_ENTITY.headOffice`) et imprimé par le générateur de bail v2. **Garde `npm run check:locations`** (`scripts/check-private-locations.mjs`) : partie exacte (les rues réelles, lues hors dépôt — secret `LVC_PRIVATE_LOCATIONS` en CI, fichier local désigné par `LVC_PRIVATE_LOCATIONS_FILE` — cherchées dans tous les fichiers du dépôt et dans `dist/`, JavaScript compris) et partie générique (« numéro + voie » dans `src/`, `scripts/` et le JavaScript de `dist/`, elle tourne même sans source) ; un échec ne cite jamais la rue (clé du lieu, fichier, ligne ; le siège social est désigné « siège social », jamais par la clé de son lieu) ; aucun fichier n'est sauté en silence (le compte rendu dit ce qui n'est pas lu et nomme les PDF, documents et archives, à contrôler à la main) ; une option inconnue est refusée ; `house-pages-check` (`exactLocationLeaks`) lit la même source. **Avant tout push**, sur un arbre propre (`git status` vide) : `npx vite build && LVC_PRIVATE_LOCATIONS_FILE=<fichier hors dépôt> npm run check:locations -- --require --require-dist` (sans ces deux options, une variable oubliée ou vide, ou un `dist/` absent, ne donnent qu'un avertissement et la commande sort 0) — le dépôt est public et la CI passe après le push, donc trop tard (emplacement du fichier : `lavilla-docs`). Le contrôle lit l'arbre de travail, pas l'historique : une rue déjà committée, même retirée depuis, partirait avec le push ; réécrire d'abord les commits locaux concernés.
